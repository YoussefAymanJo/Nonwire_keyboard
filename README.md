Nonwire_keyboard

## Description

Wireless Keyboarb based on split keyboard mechanism.As it consist of main keyboard  powered by rechargeable Battery which can operate up to week.And operated by nice Nano and soup display.The right part is Soup numpad,this numpad can operate up to week and soup friendly.
## Why it was built
I built this,beacause i always need mechanical keyboard,but i need to customize it features by myself.So this keyboard it custosmized to my needings.Also,it has customized features based on usage.Nonwire keyboard is not just regular keybaord but,desgined to be my companion.
## How to use it / Build it
Firsly,printing all 3d models after that fabricate PCB.After that assemble mx switches,MCU and battery management of pcb.then assemble all this parts together.finally,upload firmware on nice nano,the test all
